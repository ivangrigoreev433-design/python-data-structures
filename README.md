# Структуры данных и сортировки на Python

[![Python tests](https://github.com/ivangrigoreev433-design/python-data-structures/actions/workflows/tests.yml/badge.svg)](https://github.com/ivangrigoreev433-design/python-data-structures/actions/workflows/tests.yml)

Учебное задание: реализовать массив, список, дек, AVL-дерево, пузырьковую и быструю сортировки, написать тесты и запустить CI.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не нужно: код и тесты используют только стандартную библиотеку.

```bash
git clone https://github.com/ivangrigoreev433-design/python-data-structures.git
cd python-data-structures
python -m unittest discover -v
python demo.py
```

Если команда `python` недоступна, используйте `python3`.

## Файлы и возможности

| Файл | Реализация | Основные операции |
| --- | --- | --- |
| `array_struct.py` | `DynamicArray`, динамический массив на буфере `ctypes` | `append`, `insert`, `pop`, чтение/запись по индексу |
| `linked_list.py` | `LinkedList`, односвязный список | `append`, `prepend`, `pop_front`, `remove`, поиск через `in` |
| `deque_struct.py` | `Deque`, дек на двусвязных узлах | `append`, `appendleft`, `pop`, `popleft`, `peekleft`, `peekright` |
| `avl_tree.py` | `AVLTree`, сбалансированное дерево поиска | `insert`, `remove`, поиск через `in`, обход по возрастанию |
| `sorting.py` | `bubble_sort`, `quick_sort` | сортировка итерируемых данных по возрастанию |
| `test_structures.py` | тесты четырёх структур | границы, операции, внутренние инварианты, случайные последовательности |
| `test_sorting.py` | тесты сортировок | пустые и большие входы, дубликаты, сравнение с `sorted` |
| `demo.py` | демонстрация | пример использования всех реализаций |
| `.github/workflows/tests.yml` | GitHub Actions CI | тесты и демонстрация на Python 3.10, 3.12, 3.13 |

Все структуры поддерживают `len()` и перебор. В реализациях списка, дека и дерева используются собственные узлы; готовые `list`/`collections.deque`/`set` служат эталонами в тестах. Сортировки реализованы вручную, без `sorted()` и `list.sort()`.

## Правила интерфейса

- Массив автоматически удваивает ёмкость. Чтение, запись и `pop` поддерживают отрицательные индексы. Для `insert` разрешены только индексы от `0` до `len(array)` включительно; остальные вызывают `IndexError`.
- Список удаляет первое совпадение. Отсутствующее значение вызывает `ValueError`.
- Удаление из пустого массива/списка/дека и просмотр края пустого дека вызывают `IndexError`.
- AVL-дерево хранит уникальные сравнимые ключи. `insert` возвращает `True` для нового ключа и `False` для дубликата. Удаление отсутствующего ключа вызывает `KeyError`. После вставки и удаления обновляются высоты и выполняются необходимые повороты.
- Обе сортировки возвращают новый список и не изменяют вход. Элементы должны быть взаимно сравнимы. Пузырьковая сортировка устойчива. Быстрая сортировка использует явный стек и трёхчастное разбиение, не является устойчивой.
- Изменение структуры во время перебора не поддерживается.

## Сложность

| Операция | Время |
| --- | --- |
| Массив: доступ по индексу | O(1) |
| Массив: добавление в конец | O(1) амортизированно, O(n) при расширении |
| Массив: вставка/удаление в середине | O(n) |
| Список: добавление с двух концов, снятие с начала | O(1) |
| Список: поиск/удаление по значению | O(n) |
| Дек: операции с обоих концов | O(1) |
| AVL-дерево: поиск/вставка/удаление | O(log n) |
| Пузырьковая сортировка | O(n²), лучший случай O(n) |
| Быстрая сортировка | в среднем O(n log n), худший случай O(n²) |

Каждая структура занимает O(n) памяти. Обе сортировки создают копию входа O(n); пузырьковой нужно O(1) дополнительной памяти сверх копии. У быстрой сортировки стек ограничивается O(log n), поскольку меньшая часть обрабатывается первой.

## Тесты и CI

```bash
python -m unittest discover -v
```

Проверяются пустые структуры, один элемент, ошибочные индексы, повторяющиеся значения, все четыре случая балансировки при вставке, удаление разных типов узлов и последовательное удаление всего дерева. После операций с деревом проверяются порядок ключей, высоты и разница высот поддеревьев не более 1. Случайные тесты имеют фиксированные seed и воспроизводимы.

CI запускается при каждом push, pull request и вручную через вкладку **Actions → Python tests → Run workflow**. Успешный запуск отмечается зелёной галочкой.
